# Contributing

Thanks for taking a look. This is a small project, so the process is light.

1. Fork the repository and create a branch.
2. Run `npm install`, then make your change.
3. Before opening a pull request, check that these pass:
   - `npm run lint:web`
   - `npm run lint:extension`
   - `npm run build:extension`
   - `npm run build:web`
4. Describe what changed and why. For extension changes, say which pages you tried it on.

Please keep the project free of accounts, tracking and network calls to a backend. If a feature needs one, open an issue to discuss it first.
